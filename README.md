# Day by Grace (MVP)

This is the MVP (Minimum Viable Product) for **Day by Grace**, a browser-based app to help families and small groups stay rooted in Scripture and prayer.

## 🌟 Features
- 📖 Bible Reading Tracker (preset plans + custom)
- 🙏 Prayer List
- ✍️ Gratitude Journal
- 📝 Sermon Notes
- 🗓️ Church Events Tracker

## 🛠 Tech Stack
- HTML / CSS / JavaScript
- No framework required (Vanilla JS)
- Firebase or Supabase planned for login & cloud sync
- Designed to be mobile-first

## 🚀 How to Use Locally
1. Download or clone this repo
2. Open `index.html` in any browser
3. All data is currently stored in memory (browser session only)

## 🌍 To Deploy Online (Vercel)
1. Push this repo to GitHub
2. Go to [https://vercel.com](https://vercel.com)
3. Connect your GitHub account and select this repo
4. Deploy — no backend needed
