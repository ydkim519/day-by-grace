
# Day by Grace

A warm, faith-based family/group Bible tracker and journal app. Built with:
- TailwindCSS
- Firebase Auth + Firestore
- Vanilla JS

## Setup Instructions

1. Clone or download this repo
2. Add your Firebase config to `firebase.js`
3. Host with Vercel, Netlify, or Firebase Hosting

## Features
- Bible reading tracker (ESV + custom plans)
- Group/family sync
- Prayer list
- Gratitude journal
- Sermon notes
- Church events
